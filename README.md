# GREEN SAGE - Luxury Living & Furniture Atelier

A premium, high-end website for a luxury furniture brand based in Nairobi, Kenya. Features a circular minimalist logo with botanical accents, moody earthy elegance, and editorial-style design.

## 🎨 Design Features

- **Circular minimalist logo** with deep charcoal background and gold accents
- **Botanical leaf elements** wrapping around logo
- **Color palette**: Charcoal black, sage green, warm muted gold, soft ivory
- **Typography**: Elegant serif (Cormorant Garamond) + clean sans-serif (Inter)
- **Smooth animations** with fade-ins and parallax scrolling
- **Fully responsive** mobile-first design

## 🚀 Tech Stack

- HTML5
- CSS3 (with custom properties, flexbox, grid)
- Vanilla JavaScript
- Font Awesome Icons
- Google Fonts

## 🛠️ Local Development

1. Clone the repository
2. Open `index.html` in your browser
3. Make changes and refresh to see updates
